# YZT — Personal Site

🔗 **[yzt.qzz.io](https://yzt.qzz.io)**

A minimal, handcrafted personal site built with pure HTML, CSS, and JavaScript. No frameworks, no build tools — just code.

## Features

- 🌗 Dark / Light theme toggle
- 🌐 Chinese / English language switch
- 🎲 3D cube loading animation
- 👀 Eyes that follow your cursor (with blink animation)
- 📜 Infinite marquee ticker
- 📊 Scroll progress bar
- 🎯 Custom cursor with trailing ring
- 📱 Fully responsive / mobile-optimized
- 🗺️ Pentest roadmap page

## Tech Stack

- HTML5 + CSS3 + Vanilla JS
- Google Fonts (Noto Serif SC, Playfair Display, Courier Prime)
- Deployed on **Cloudflare Pages**
