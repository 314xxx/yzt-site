# YZT — 个人网站

🔗 **[yzt.qzz.io](https://yzt.qzz.io)**

一个纯手工打造的极简个人网站，纯 HTML + CSS + JavaScript，无框架、无构建工具。

## 特性

- 🌗 深色 / 浅色主题切换
- 🌐 中 / 英语言切换
- 🎲 3D 立方体加载动画
- 👀 眼睛跟踪鼠标移动（含眨眼动画）
- 📜 无限循环滚动标语
- 📊 页面滚动进度条
- 🎯 自定义光标 + 拖尾光环
- 📱 完整响应式 / 移动端适配
- 🗺️ 渗透测试路线图页面

## 技术栈

- HTML5 + CSS3 + 原生 JS
- Google Fonts（Noto Serif SC、Playfair Display、Courier Prime）
- 部署于 **Cloudflare Pages**

## 项目结构

```
├── index.html              # 主页
├── style.css               # 当前样式
├── script.js               # 当前脚本
├── pentest-roadmap.html    # 渗透路线图
├── 404.html                # 404 页面
├── eyes-demo.html          # 眼睛效果演示
├── robots.txt
├── sitemap.xml
├── CNAME                   # yzt.qzz.io
└── deploy.sh               # 部署脚本
```
